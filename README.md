# صداك (Sadaak)

# نظرة عامة
صداك هو نظام صحي ذكي يساعد المستخدم على متابعة حالته الصحية بشكل مستمر وتحويلها إلى تقارير منظمة تدعم الفهم وتسهل على الطبيب التشخيص.

# المشكلة
تعتمد الرعاية الصحية الحالية على لحظات متفرقة (زيارة الطبيب فقط)، ولا يوجد نظام صحي مستمر يرافق المستخدم ويسجل حالته بشكل متكامل، مما يؤدي إلى فقدان كثير من المعلومات المهمة وصعوبة فهم الحالة بشكل دقيق.

##الحل
يوفر صداك نظامًا صحيًا مستمرًا يقوم بتتبع حالة المستخدم وتحليلها وتحويلها إلى تقارير واضحة ومنظمة، مما يساعد على فهم الحالة الصحية بشكل أفضل ويدعم اتخاذ قرارات طبية أدق وأسرع.

#المميزات
* إنشاء تقارير طبية منظمة من مدخلات المستخدم
* متابعة المؤشرات الحيوية (بيانات محاكية)
* تذكير ذكي بالمواعيد والأدوية
* تجربة بسيطة وسهلة الاستخدام

# التشغيل
1. افتح الملف في Google Colab
2. شغّل جميع الخلايا
3. سيتم إنشاء رابط مباشر (Gradio) يمكن من خلاله تجربة النظام
4.تم تصميم واجهات المستخدم بشكل منفصل لتمثيل تجربة الاستخدام  
#كيف يعمل
1. إدخال بيانات المستخدم
2. تحليل الحالة باستخدام الذكاء الاصطناعي
3. إنشاء تقرير صحي منظم
4. تخزين ومتابعة البيانات مع الوقت
5. إرسال تذكيرات مخصصة

# التقنيات المستخدمة

* لغة python
* النماذج اللغوية (LLM) لتحليل البيانات وإنشاء التقارير
* لعرض النموذج الاولي Gradio
